ATACAREJO SITE NOVO — versão revisada

Estrutura correta do projeto:
- server.js
- package.json
- public/index.html
- public/produto.html
- public/carrinho.html
- public/admin-login.html
- public/admin.html

Correções desta versão:
1. Corrigido o INSERT de produtos: a versão anterior tinha 20 campos e apenas 19 placeholders.
2. Painel administrativo realmente usa múltiplas fotos (até 8), preços de varejo/atacado, mínimo atacado, fornecedor, origem e dimensões.
3. Cadastro de fornecedores com nome, empresa, CEP, WhatsApp e observações.
4. Produto vinculado a fornecedor/origem.
5. Carrinho com botão Comprar funcionando e modal: continuar vendo produtos ou finalizar compra.
6. Galeria de fotos no produto.
7. Separação de remessas por origem no cálculo de frete.
8. Preço de varejo padrão: custo x 1,40 (40% de acréscimo sobre o custo), quando não informado.
9. SQL inclui migração para bancos antigos.
10. Não há arquivos HTML duplicados na raiz: tudo fica dentro de public/.

Variáveis do Render/Supabase:
- ADMIN_EMAIL
- ADMIN_PASSWORD
- DATABASE_URL
- JWT_SECRET
- OWN_STOCK_CEP=37795-970
- WHATSAPP_NUMBER (se for usado em futura integração)

Frete:
O projeto já separa o carrinho por origem, mas o preço/prazo real do frete ainda precisa de credencial/API de um provedor (ex.: Melhor Envio ou Correios). Não inventa valor de frete.

Importante sobre imagens:
Este pacote salva uploads em public/uploads. No Render Free, o filesystem local pode ser apagado em reinícios/redeploys. Para produção, a próxima etapa recomendada é migrar as imagens para armazenamento persistente (ex.: Supabase Storage).

Deploy:
npm install
npm start
